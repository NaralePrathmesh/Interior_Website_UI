Put the client's own project photographs in this folder.

Then open lib/data.js, find the PHOTOS list,
and replace each Unsplash link with the matching file, for example:

  hero:'/assets/images/hero-interior.jpg',
  living1:'/assets/images/living-room-01.jpg',
  kitchen1:'/assets/images/kitchen-01.jpg',

Suggested sizes: 2000 px wide for the hero, 1600 px for everything else,
saved as JPG at about 80% quality (300–500 KB each).

Photos can also be changed without editing code: Admin panel > Projects /
Services / Gallery > Edit > upload a file or paste an image link.

The placeholder photos currently used come from Unsplash (unsplash.com/license),
which allows free commercial use. Replace them with the client's real work
before launch so the portfolio shows projects the studio actually delivered.
